# Интеграция с внешними сервисами (эмуляция) — кейс 2


## 1\. БКИ (Бюро кредитных историй) 

**Назначение:** получить кредитный скор, флаг просрочки, число запросов за 90 дней.

**Контракт запроса:**

```json
POST /bki/score
{
  "passport\\\_hash": "a1b2c3d4e5f6a7b8"
}
```

**Контракт ответа (успех):**

```json
{
  "score": 720,
  "delinquency": false,
  "requests\\\_90d": 1
}
```

**Правила эмуляции (детерминизм):**

* Взять `h = int(hashlib.md5(passport\\\_hash.encode()).hexdigest(), 16) % 10`.
* Если `h <= 5` → `score` = 600 + h\*20 (600–700), `delinquency` = false.
* Если `6 <= h <= 8` → `score` = 450 + (h-6)\*50 (450–550), `delinquency` = false.
* Если `h == 9` → `score` = 400, `delinquency` = true.
* `requests\\\_90d` = 1 (фиксировано).

**Таймаут:** 3 секунды. При превышении — вернуть `TIMEOUT`.

## 2\. СМЭВ (Система межведомственного электронного взаимодействия) 

**Назначение:** проверить соответствие паспортных данных клиента

**Контракт запроса:**

```json
POST /smev/check
{
  "client\\\_id": "cli_0001",
  "passport\\\_hash": "f727a849055f2224"
}
```

**Контракт ответа (успех):**

```json
{
  "status": "MATCH"
}
```

**Правила эмуляции (детерминизм):**

* Взять `h = int(hashlib.md5(client\\\_id.encode()).hexdigest(), 16) % 10`.
* Если `h == 0` → `status` = `MISMATCH`.
* Иначе → `status` = `MATCH`.
* `status` = `TIMEOUT` — если эмулятор «спит» > 3 секунд.

**Таймаут:**
3 секунды. При превышении — вернуть `TIMEOUT`, решение конвейера `NEED_MORE_DATA` с reason `EXTERNAL_TIMEOUT`.

\---

## 3\. Логирование вызовов (audit) 

Каждый вызов внешнего сервиса должен записываться в файл `external.log`.

|Поле|Пример|Зачем нужно|
|-|-|-|
|timestamp|2025-11-01T10:00:00Z|Время события. Когда именно это произошло (чтобы можно было найти в истории)|
|service|BKI|имя сервиса откуда берем информацию|
|request_id|req_0001|уникалиный номер запроса|
|status|SUCCESS|результат вызова (итог: успешно, таймаут или ошибка)|
|latency_ms|420|скорость ответа в миллисекундах|
|result|{"status": "MATCH"}|краткий ответ сервиса (что именно пришло)|

\---

## 4\. Поведение при таймауте 

Опишите своими словами, что происходит, если внешний сервис не ответил вовремя:

1. **Что возвращает эмулятор при таймауте?** — Эмулятор возвращает статус TIMEOUT (не ответил вовремя)
2. **Какое решение принимает кредитный конвейер?** — Конвейер выдает NEED_MORE_DATA. Он не отказывает клиенту, потому что это технический сбой, а не вина клиента
3. **Какой reason записывается в итоговое решение?** — EXTERNAL_TIMEOUT (внешний таймаут)
4. **Можно ли повторить запрос к внешнему сервису?** — Да, можно сделать одну повторную попытку через 0.5 секунды. Если снова таймаут — сдаемся
5. **Что видит клиент на экране своего приложения?** — Клиент видит сообщение: "Проверяем данные, попробуйте позже". Он не видит слово "ОТКАЗ"
